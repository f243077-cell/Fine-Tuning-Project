# How to return a product

To return a product, open the "My Orders" page on the website and choose "Request return", or call the support line. The support team sends a return code within one working day.

Pack the product in its original box with all accessories and write the return code on the box. A courier collects the parcel from the customer's address within 3 working days. Returns are free when the product is faulty or wrong; otherwise a pickup charge of Rs. 200 applies.

The refund or replacement is processed after the warehouse inspects the item, usually within 2 working days of arrival.
